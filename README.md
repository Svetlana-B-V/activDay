# 🔥 GitHub Active Days Counter

Простой и красивый счётчик активных дней коммитов на GitHub. Помогает отслеживать прогресс в челленджах типа «100 дней кода», «365 дней коммитов» и подобных.

Подтягивает реальные коммиты через GitHub API и показывает их в виде привычного графика активности (как на GitHub).

## ✨ Возможности

- 📊 **Статистика в реальном времени**
  - Дней прошло с начала челленджа
  - Активных дней (коммиты + ручные отметки)
  - Дней осталось до цели
  - Календарных дней до дедлайна

- 🟩 **Визуализация активности**
  - Сетка в стиле GitHub contribution graph
  - Кликаешь по дню — отмечаешь как активный
  - Hover-подсказки: откуда данные (API или ручная отметка)

- 🔌 **Интеграция с GitHub API**
  - Автоматическая загрузка коммитов
  - Кэширование данных (не дёргает сеть каждый раз)
  - Поддержка до 300 последних событий (~90 дней)

- 💾 **Локальное хранение**
  - Всё сохраняется в `localStorage` браузера
  - Не нужен сервер или база данных
  - Работает оффлайн (после первой загрузки)

- ⚠️ **Умные предупреждения**
  - Если цели уже не успеть достичь — скажет об этом
  - Показывает прогресс к цели

## 🚀 Как запустить

### Способ 1: Просто открыть файл

1. Скачай или скопируй файл `index.html`
2. Открой его двойным кликом в любом браузере
3. Готово! Сервер не нужен.
